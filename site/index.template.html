          How it works
          
    Props per theme, written in at commit time.
    
          
    Shadewind remembers each view's props for every theme and rewrites them inside React Native's own shadow tree commit.
    
        
    
        
    
          
    JS
    setTheme('dark')
    
          
    C++
    A native commit hook picks it up
    
          
    Shadow tree
    Each bound view's dark props are written in
    
          
    Fabric
    Mounted in the same commit
    
          
    your React components → nothing to do
    
        
    
        
    
          
    Animated switch, optional
    setTheme('dark', { transition: { type: 'fade', durationMs: 250 } }) cross-fades. Instant by default.
    
          
    Precompile, optional
    precompileClassNames: true turns classNames on View and Text into hookless components to cut mount cost.
    
          
    See what it binds
    A dev-only diagnostics log lists every view it binds and every commit it themes.
    
          
    Tested natively
    A harness runs React Native's real C++ renderer, so commit logic is checked without a device.
    
          
    Honest fallbacks
    Inline backgrounds over a className colour and active: states re-render, as in plain Uniwind.
    
          
    Bounded memory
    Since 0.3.2 the style cache is bounded, so thousands of new classNames don't grow the process.
    
        
    
      
    
    
    

    
    
      
    
        
    
          Benchmark · 2003 views · Release builds
          
    Against plain StyleSheet, the floor.
    
          
    StyleSheet is React Native with no styling library, the fastest anything can mount. Time is measured until the JS thread is idle, ten runs each. These are simulator and emulator numbers; nothing has been measured on a physical device yet.

    JS-thread time; zero components re-render. Colours reach the screen about {{visualIos}} ms (iOS) and {{visualAndroid}} ms (Android) after the call, and that main-thread mount is React Native's own work. A StyleSheet app has no runtime theme switch to time, so there is no baseline lane here.
    
        
    

        
    
          
    
            
    
            
    classNames seen {{memoryTo}}
    
            
          
    
          
    
          
    The example-real soak mounts and unmounts about 1,200 views per cycle, 200 of them with a className never seen before. Each reading is the process footprint after two forced GCs. 0.3.2 bounds the style cache. Its lower second reading is warm-up, not shrinkage, and mount time did not change. A normal app with a fixed set of classNames did not grow in any build.

          Status & docs
          
    Experimental, and upfront about it.
    
        
    
        
    
          
    0.x · New Architecture only
    React Native 0.86. iOS is the primary target; Android has one emulator of testing so far. Verified with Uniwind 1.12.x, and 1.13.x without the native class resolver. Other versions run as plain Uniwind.
